# Управление заявками на мероприятия
Русскоязычное учебное веб-приложение AnalystCraft для взрослой бизнес-аудитории. Сотрудник фиксирует идею, организатор принимает решение, ответственный готовит мероприятие. Успех: полный наблюдаемый маршрут от заявки до готовности без потерянного решения.

## Подтверждённая поверхность
Три экрана: список, карточка, план подготовки. Desktop и mobile, клавиатура, доступные подписи, пустые и ошибочные состояния. React/Vite, отдельный runtime-репозиторий; stateless HTTP 8080, /health. Данные localStorage, личные для браузера, без серверной базы. Учебные роли, без регистрации и авторизации. Внешняя публикация только владельцем.

## Предоставленный контекст и допущения
Источник: последние два хода чата 01a0b3dd-2522-7af1-b8d3-c175c2dc91fa, прочитаны 09.10.2026. Последний расширенный кейс имеет приоритет. Пользователь разрешил выбирать минимальные coherent детали без дополнительных согласований.
Допущения: бюджет в рублях, неотрицательное число; дата может быть любой (ретроспективные заявки допустимы); название обязательно даже для черновика, остальные поля обязательны для отправки, включая аудиторию и бюджет. Все три обязательные задачи фиксированы. Готовность вычисляется автоматически и исчезает при снятии отметки. Сотрудник редактирует черновик/возврат; организатор решает; ответственный выполняет задачи. Нет реальных персональных данных.

## Риск и приёмка
Учебная демонстрация, ошибки обратимы, низкая зависимость и свободный выход. Нельзя применять как многопользовательскую рабочую систему. Инженерная проверка e2e отдельно от UAT владельца. Визуальное направление: спокойный рабочий интерфейс, светлая поверхность, читаемые реестры и ясные статусы; маркетинговый лендинг не нужен.
