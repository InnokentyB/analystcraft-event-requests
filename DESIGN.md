# Рабочий реестр
Режим Operate. Пользовательский brief: аккуратное взрослое бизнес-приложение; выбор минимальных деталей разрешён владельцем. Светлый реестр с глубоким зелёным навигационным полем, ясной типографикой и строками, разделёнными тонкой линией. Идея: решения не теряются, следующая работа всегда видна.
Рассмотрены: деловой журнал, редакционная очередь, календарь конференции, диспетчерский реестр (выбранная четвёртая структура), протокол заседания, проектная папка, расписание учебного центра. Каталожные альтернативы уступают по ясности процесса: графическая сетка слишком плотна, кодированные цвета требуют обучения, консоль предполагает техническую аудиторию, атлас скрывает последовательность, транспортные табло преувеличивают дату вместо решения. Сохраняем дисциплину стабильных строк, компактных колонок и изоляции действий.
Палитра: #173b35 навигация, #f4f5f0 фон, #ffffff рабочая поверхность, #172b27 текст, #52645d вторичный текст, #b75323 возврат, #276653 согласование. Состояния названы словами и отмечены цветом. Шрифт системный для рабочего UI; крупный заголовок без декоративной гарнитуры. Иконки Lucide, без emoji. Desktop: навигация слева, широкая рабочая область; mobile: верхняя полоса, вертикальный реестр и формы в одну колонку.
